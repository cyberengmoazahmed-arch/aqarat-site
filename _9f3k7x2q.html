الأمان الإضافي (IP + كود تليجرام)

طبقتين اختياريتين فوق الإيميل والباسورد — الشغل بطيء شوية بس أأمن
سيبها فاضية = مسموح من أي جهاز. ملاحظة: الـ IP بيتغيّر مع الموبايل/الراوتر — لو اتحجزت، احذف السطر من data/auth.js.
تجهيز التليجرام (3 دقايق):
  1. افتح تليجرام وابحث عن @BotFather ← /newbot ← اديه اسم، هيدوسلك Token
  2. ابحث عن روبوتك وأرسله أي رسالة (زي hi)
  3. افتح https://api.telegram.org/bot<TOKEN>/getUpdates في المتصفح — هتلاقي "chat":{"id":123... — ده الـ Chat ID
  4. الصق الاتنين فوق وفعّل الخانة ودوّس «حفظ الأمان»
تحذير صريح: الموقع ثابت (static) فـ الـ Bot Token متخزّن في data/auth.js اللي أي حد يقدر يقراه — ميزة إنه مش هيشوف رسائلك، بس يقدر يبعتلك رسائل مزعجة بنفس الروبوت. لو عايز حماية أقوى محتاج سيرفر (Backend).

الاتصال بـ GitHub (النشر التلقائي)

لما تكون متصل، أي حفظ بيتعمل commit على الريبو والصفحة بتتحدث أوتوماتيك في دقيقة
بيتخزن في المتصفح بتاعك بس — مش بيتنشر على الموقع أبداً.
عملية التوكن مرة واحدة (5 دقايق):
  1. افتح github.com/settings/tokens
  2. دوّس Generate new token (classic)
  3. حدد صلاحية repo واضغط Generate
  4. انسخ التوكن والصقه فوق واكتب اسمك واسم الريبو
