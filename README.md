# عقاراتي — موقع عقارات (إيجار + تمليك)

موقع ثابت (HTML/CSS/JS) للعقارات:
- زباين يشوفوا الشقق بفلاتر (إيجار / تمليك / مفروش / المدينة / السعر / بحث)
- دوسة **«احجز»** بتفتح واتساب `01028960555` برسالة جاهزة فيها بيانات الشقة + بيانات العميل
- **لوحة تحكم مخفية** تضيف وتشيل وتعدّل الشقق وترفع صور من الموبايل (المسار مش معلن في الموقع)
- الحفظ بيتعمل commit على الريبو مباشرة لو ربطت GitHub — والصفحة بتتحدث أوتوماتيك في ~دقيقة

---

## 1) تشغيل الموقع محلياً

```powershell
cd D:\aqarat-site
python -m http.server 8000
```
ثم افتح:
- الموقع: http://localhost:8000/index.html
- لوحة التحكم: المسار مكتوب في `PRIVATE-NOTES.txt` (موجود محلياً فقط ومش مرفوع على GitHub)

> الدخول: **إيميل + كلمة سر** (بياناتك في `PRIVATE-NOTES.txt`) — مفيش كلمة سر افتراضية، و5 محاولات غلط = محجوب 15 دقيقة.

---

## 2) الرفع على GitHub (زي موقع IconFit بالظبط)

### أ — إنشاء الريبو ورفع الملفات
```powershell
cd D:\aqarat-site
git init
git add .
git commit -m "first commit: aqarat site"
```
ثم من [github.com/new](https://github.com/new):
1. أنشئ ريبو جديد (مثلاً `aqarat-site`) — **Public** أو Private براحتك
2. نفّذ:
```powershell
git remote add origin https://github.com/USERNAME/aqarat-site.git
git branch -M main
git push -u origin main
```

### ب — تفعيل GitHub Pages
1. افتح صفحة **Settings → Pages** في الريبو
2. من فرع `main` ومجلد `/ (root)` → **Save**
3. بعد دقيقة: `https://USERNAME.github.io/aqarat-site/`

---

## 3) ربط GitHub بالأدمن بانل (النشر التلقائي)

من غير الرابط، أي حفظ بينزّل ملف `listings.js` وتستبدله بنفسك. **بالرابط** كل حفظ بيتنشر لوحده.

### إنشاء التوكن (مرة واحدة — 5 دقايق)
1. افتح [github.com/settings/tokens](https://github.com/settings/tokens)
2. **Generate new token (classic)**
3. علّم صلاحية **repo** → **Generate**
4. انسخ التوكن

### إدخاله
1. افتح لوحة التحكم (المسار في `PRIVATE-NOTES.txt`) → تبويب **الإعدادات**
2. املا: اسم مستخدم GitHub + اسم الريبو + الفرع (`main`) + التوكن
3. دوس **«اختبار الاتصال»** → لازم يقول ✅
4. دوس **«حفظ الاتصال»**

> التوكن بيتحفظ في متصفحك **بس** (localStorage) — مش بيتنشر على الموقع أبداً.

---

## 4) إضافة شقة جديدة

1. افتح لوحة التحكم → دخول بالإيميل وكلمة السر
2. **+ إضافة شقة** → املأ البيانات → ارفع الصور (أو الصق لينك صورة)
3. **💾 حفظ ونشر**
   - لو متصل GitHub: بيتعمل commit والصفحة تتحدث خلال دقيقة
   - لو مش متصل: الملف بينزّل — استبدله في `data/listings.js` وارفعه

**ملاحظات:**
- الصورة الأولى هي صورة الغلاف
- **السعر اختياري** — سيبه فاضي وهيظهر للزوار «السعر عند الاتصال»
- `0` في غرف النوم = استديو
- رقم الواتساب للطلبات يتغير من الإعدادات (بيتحوّل لصيغة دولية تلقائياً)

## 6) حل مشاكل

| المشكلة | الحل |
|---|---|
| الصفحة مش بتتحدث بعد الحفظ | استنى دقيقة (GitHub بيبني من جديد) — الموقع بيجيب البيانات كل زيارة من غير كاش |
| التوكن رفض (403) | التوكن لازم يكون classic فيها صلاحية `repo` |
| «مش لاقي الريبو» | اتأكد من اسم المستخدم والريبو والفرع |
| نسيت كلمة السر | غيّرها من تبويب «بيانات الدخول» بعد ما تدخل القديمة — أو من `data/auth.js` (التفاصيل في `PRIVATE-NOTES.txt`) |
| صور مش ظاهرة | الصور لازم تكون في `assets/listings/` على الريبو (الأدمن بيرفعها تلقائياً لو متصل) |

## 7) الأمان

- **لوحة التحكم مخفية**: مفيش أي رابط ليها في الموقع ولا في الـ README، ومربوطة بـ `robots.txt` + `noindex`
- **دخول مزدوج**: إيميل + كلمة سر (مش كلمة سر بس)
- **تشفير قوي**: كلمة السر متخزنة PBKDF2-SHA256 بـ 150,00 تكرار + salt عشوائي
- **قفل تلقائي**: 5 محاولات غلط = محجوب 15 دقيقة
- **جلسة آمنة**: خروج تلقائي بعد 30 دقيقة بدون نشاط
- **CSP**: صفحة Content-Security-Policy تمنع أي سكربت خارجي أو تنفيذ كود غير مخطط له
- **توكن GitHub**: محفوظ في متصفحك فقط (localStorage) ولا يُرفع للريبو أبداً
- **ملف بيانات الدخول منفصل** (`data/auth.js`) — الموقع العام مبيقرأهوش

> تنبيه: أي موقع ثابت (static) بيعرض ملفات البيانات للمتصفح — الأمان الحقيقي هو قوة كلمة السر + إخفاء المسار + قفل المحاولات. لو عايز حماية أقوى من كده محتاج سيرفر/Backend.
